# PCB Developers

Programmer Records System - a static site built with HTML, CSS, and JavaScript connected to Supabase.

## Features

- View programmers, projects, and media gallery
- Admin login to add, edit, and delete entries
- Dark mode and English/Spanish language toggle
- Responsive design for mobile and desktop
- Video and photo carousel

## Deployment

This site is configured for GitHub Pages.

## Setup

1. Clone the repository
2. Open `index.html` in a browser or serve the files with any static server
3. For admin features, use the password set in `index.html`

## Tech Stack

- HTML5 / CSS3 / JavaScript (ES modules)
- Supabase (PostgreSQL + Storage)
- GitHub Pages for hosting
